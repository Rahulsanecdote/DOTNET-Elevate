# **App Name**: .NET Elevate

## Core Features:

- .NET Learning Roadmap: Presents a structured .NET learning path from fundamentals to advanced topics, including interactive lessons, quizzes, and practice exercises.
- AI-Powered Spaced Repetition: Generates flashcards based on lesson content and user performance, employing a spaced repetition algorithm to optimize knowledge retention. Tool learns from mistakes and creates targeted review sessions.
- Resume Tailoring Assistant: Analyzes job descriptions and user resumes to identify skill gaps and suggests tailored resume revisions. Generates improved resume bullets with quantified impact using generative AI tools.
- Interview STAR Story Builder: Helps users craft compelling STAR (Situation, Task, Action, Result) stories for behavioral interviews, providing question prompts, structure guidance, and AI-driven feedback on story content. Tool supports iteration to optimize answers.
- Coding Challenge Environment: Provides a platform for practicing coding problems with a built-in test harness and post-solution code review, covering .NET/C# concepts and API design.  Stores user code in Firestore.
- AI Chat Assistant: An AI chat assistant capable of operating in different modes (Learn, Recruiter, Interview, Work) to provide context-aware support, generate text, and answer questions using RAG with citations. Supports toggling on/off saving user conversation data. PII is automatically scrubbed by a tool.
- Job Application Tracker: Enables users to track job applications, companies, contacts, and communication history, including automated follow-up reminders and message generation.

## Style Guidelines:

- Primary color: Slate Blue (#7A88BE) for a calm, professional feel, fitting for developers and career growth.
- Background color: Dark slate gray (#2F4F4F), providing a modern dark-mode aesthetic suitable for long coding sessions and focus.
- Accent color: Pale turquoise (#AFEEEE) to highlight key elements, CTAs, and interactive components.
- Headline font: 'Space Grotesk' (sans-serif) for a computerized, techy feel, to be used in combination with 'Inter'.
- Body font: 'Inter' (sans-serif) for a modern, neutral, and readable interface. 
- Code font: 'Source Code Pro' (monospace) for displaying code snippets, providing easy readability.
- Use simple, line-based icons to represent various features and actions, ensuring clarity and consistency.
- Maintain a clean, minimal layout with ample whitespace and clear information hierarchy.
- Implement subtle animations for transitions and loading states to improve user experience without being distracting.
